# youtube-extensions

Chrome extensions for YouTube.
YouTube 用の Chrome 拡張機能を集めたリポジトリです。

| Extension / 拡張機能 | Description / 内容 |
| --- | --- |
| [Live Jump for YouTube / ライブジャンプ for YouTube](youtube-live-hotkey/) | One key (e.g. F2) jumps a paused live stream back to live, and plays or pauses everything else.<br>F2 などのキーで、ライブ配信の一時停止中は「ライブ」ボタンを押して最新の配信位置へ移動し、それ以外は再生 / 一時停止を切り替える |

Chrome Web Store listing text and images are in [`store/`](store/).
Chrome ウェブストアに掲載する文章と画像は [`store/`](store/) にあります。
