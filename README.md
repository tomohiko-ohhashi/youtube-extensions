# youtube-extensions

Chrome extensions for YouTube.<br>
YouTube 用の Chrome 拡張機能を集めたリポジトリです。

## Live Jump for YouTube / ライブジャンプ for YouTube

![Live Jump for YouTube](store/youtube-live-hotkey/screenshot-1-en.png)

**English**: One key (F2 by default) jumps a paused YouTube live stream back to live, and plays or pauses everything else.

**日本語**: キーひとつ（初期設定は F2）で、ライブ配信の一時停止中は「ライブ」ボタンを押して最新の位置から再生し、それ以外は再生 / 一時停止を切り替えます。

➡️ Install and usage / インストールと使い方: [`youtube-live-hotkey/`](youtube-live-hotkey/)
